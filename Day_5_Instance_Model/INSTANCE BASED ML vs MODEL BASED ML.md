**INSTANCE BASED ML vs MODEL BASED ML**



\-> types of machine learning based on how the ML model learns

&#x09;-> Instance Based learning

&#x09;-> Model based learning



\-> ML model learn by 

&#x09;-> Memorizing : keep in memory

&#x09;-> Generalizing : understanding



\-> Instance based learning 

&#x09;-> Model memorize the data

&#x09;-> Ex: we have a dataset

&#x09;	-> iq | cgpa | placement(y/n)

&#x09;-> instance based learning models keep the dataset as it as and draw no patterns 

&#x09;-> Now for the new input, model find the similarity with other points (distance)

&#x09;-> then it gets some closest points and put the new data point in the category 

&#x09;	where the most of the closest point lies.

&#x09;-> KNN model



\-> Model based learning

&#x09;-> these models find a mathematical relationship between the input and output

&#x09;-> then predict the output based on that relationship

&#x09;-> after training does not require training points

&#x09;-> Ex: Linear regression , Logistic regression , decision tree
