**UNIVARIATE ANALYSIS**



\-> EDA -> Exploratory data analysis

&#x09;-> its purpose is to completely understand the data

&#x09;-> EDA is done by using the following methods

&#x09;	-> univariate analysis

&#x09;	-> bivariate analysis

&#x09;	-> multivariate analysis

&#x09;

\-> Univariate analysis

&#x09;-> when we do the analysis of each column/variable in a data independently, it is

&#x09;	univariate analysis



\-> data is of two types

&#x09;-> numerical data

&#x09;	-> data is in numbers form

&#x09;	-> ex: height, weight, age

&#x09;-> categorical data

&#x09;	-> data is of categorical form

&#x09;	-> ex: spam/not spam , nationality





\-> a dataset contains numerical and categorical columns

\-> Univariate analysis

&#x09;-> find the nature of the column

&#x09;	-> according to it do plotting

&#x09;-> we need to plot the graph as hidden patterns in the data are extracted from

&#x09;	data visualization



\-> for the categorical data column

&#x09;-> count the frequency of each value in the column and plot the bar chart

&#x09;-> draw the pie chart



\-> for the numerical data column

&#x09;-> plot the histogram

&#x09;-> plot boxplot

&#x09;	-> help to know the outliers



\-> percentile

&#x09;-> Ex: this value is 25 percentile

&#x09;	-> means 25% values are less than this value



\-> 5 number summary

&#x09;-> Q1 -> 25 percentile

&#x09;-> Q3 -> 75 percentile

&#x09;-> IQR (Interquartile Range) -> Q3 - Q1

&#x09;-> Minimum -> Q1 - 1.5\*IQR

&#x09;-> Maximum -> Q3 + 1.5\*IQR

&#x09;-> values less than minimum and greater than maximum are outliers
