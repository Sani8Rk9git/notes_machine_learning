**BIVARIATE ANALYSIS**



\-> doing the analysis on data by taking two columns together at a time.



\-> if we have two columns taken for analysis, we can have the following:

&#x09;-> Numerical vs Numerical

&#x09;-> Categorical vs Categorical

&#x09;-> Numerical vs categorical



\-> numerical vs numerical

&#x09;-> scatter plot



\-> numerical vs categorical

&#x09;-> bar plot



\-> Dist plot

\-> Heatmap

\-> Cluster map

\-> Pair plot

\-> Line plot



\-> in multivariate analysis, we take more than 2 columns simultaneously and do the analysis
