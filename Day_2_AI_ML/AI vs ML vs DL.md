**AI vs ML vs DL**



\-> Artificial Intelligence (AI) is a technique in computer science to create systems that can solve problems that usually require human intelligence.





\-> Intelligence / human intelligence 

&#x09;-> it the capacity of a system to 

&#x09;	-> perceive information	

&#x09;	-> learn from experience

&#x09;	-> reason about situations

&#x09;	-> solve problems

&#x09;	-> plan actions

&#x09;	-> memorize things

&#x09;	-> adapt to changes 

&#x09;	-> pursue goals effectively

&#x09;	-> creativity and imagination

&#x09;	-> emotional intelligence



\-> AI is mostly pattern recognition



\-> Earlier AI was symbolic AI and expert systems

&#x09;-> basically a program with multiple if-else conditions

&#x09;-> the problem is they provide solutions to specific problems only

&#x09;-> if a problem is given whose logic is fuzzy means (a problem that involve consideration for various degree of truth instead of true-false choices)

&#x09;	-> image classification , voice recognition

&#x09;-> here the symbolic AI fails





\-> ML (Machine learning)

&#x09;-> subset of AI

&#x09;-> no explicit programming

&#x09;-> data ---> algo ---> pattern

&#x09;-> helps in fuzzy logic

&#x09;	-> we do not need to write the rules 

&#x09;	-> just give data 

&#x09;-> The problem with machine learning is we have to provide the features 

&#x09;	ourselves(input features)

&#x09;	-> creating features require the knowledge about the data

&#x09;-> as we give more data, the ML algo performance increases but after a 

&#x09;	certain range, the performance stabilize.

&#x09;





\-> DL (deep learning)

&#x09;-> it is subset of ML

&#x09;-> same as ML

&#x09;	-> give data

&#x09;	-> algo learn the pattern

&#x09;-> It is different from ML as DL uses algorithms that are inspired from 

&#x09;	human neurons

&#x09;-> it is mathematical based, the smallest unit (perceptron) is based on 

&#x09;	biological neurons

&#x09;-> It overcomes the problem of ML as the algorithm automatically detect the 

&#x09;	features from the data itself

&#x09;-> DL is very useful for solving problems where we do not know what features

&#x09;	could exist

&#x09;-> as layers increases, the performance increases

&#x09;-> as more and more data is provided, the performance of the algo increases
