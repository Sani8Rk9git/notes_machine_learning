**UNSUPERVISED MACHINE LEARNING**



\-> If in the data we have only input columns and no output columns, it is unsupervised ML



\-> Ex: we have data of 5000 students with two input columns



iq | cgpa

..



\-> the task here is not prediction as we do not have the output column



\-> In unsupervised learning we do 4 things:

&#x09;-> Clustering 

&#x09;	-> clustering algorithm can detect groups among the data

&#x09;	-> can categorize the inputs

&#x09;	-> helps in analysis

&#x09;	-> can also do hierarchical clustering (forming sub-groups 

&#x09;		in groups)

&#x09;-> dimensionality reduction

&#x09;	-> remove the extra columns that have no impact on the output

&#x09;	-> can combine 2 or more related columns into a single columns

&#x09;		-> this is feature extraction 

&#x09;	-> also help in visualization as make the higher dimension 

&#x09;		data into 3 dimension to plot on the graph

&#x09;-> Anomaly detection

&#x09;	-> detect outliers

&#x09;-> Association rule based learning

&#x09;	-> finding association/relationship between different products

&#x09;	-> finding how different things are related
