**SUPERVISED ML**



\-> ML is all about learning from data (getting trained on data)

\-> Now if in the data we have Input and Output and our task is to find a relationship between input and output so that for the new input we can predict the output then this type of learning is Supervised learning







Ex: we have the student data for 5000 students



iq | cgpa | Yes/No placement

87   7.4    Y

...



\-> iq and cgpa is the input column

\-> Y/N placement is the output column

&#x09;-> depends on both the input columns



\-> in this data, we have both input and output

\-> Now the task for the ML algorithm is to find a mathematical relationship/patterns between input and output

\-> now the ML algorithm can answer for new students

\-> this is supervised ML





\-> Supervised ML has 2 types : Regression  Classification



\-> Types of Data:

&#x09;-> Numerical Data: Ex: age, weight, cgpa, iq

&#x09;	-> can contain many numbers

&#x09;-> Categorical Data: Ex: gender, nationality

&#x09;	-> contains some category



\-> Regression

&#x09;-> if in the supervised machine learning problem, the output column 

&#x09;	is numerical then it is Regression



\-> Classification

&#x09;-> if in the supervised machine learning problem, the output column

&#x09;	is categorical then it is classification
