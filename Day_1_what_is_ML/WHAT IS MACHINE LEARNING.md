**WHAT IS MACHINE LEARNING?**



\-> Machine Learning (ML) is a field of computer science which used Statistical techniques to give computer systems the ability to Learn from data without being explicitly programmed.





\-> Data 

&#x09;-> Any collection of facts, numbers, measures, observations or other 

&#x09;	descriptions of things that convey information about those things is

&#x09;	called data.



\-> Statistics

&#x09;-> The term statistics refers to the study of collecting, organising, 

&#x09;	analysing, interpreting, and presenting data. 



\-> Statistical question

&#x09;-> A statistical question is a question that can be answered by collecting 

&#x09;	data. 

&#x09;->  we can collect data, analyse it, and make conclusions 



\-> explicit programming

&#x09;-> we write code for handling every case/scenario

&#x09;-> we write the program 

&#x09;-> Input ---> program ---> output



\-> In ML

&#x09;-> we give data (input and output) to ML algorithm

&#x09;-> the ML algorithm generate mathematical relationship / patterns in data

&#x09;-> for new input , it gives the output



\-> Mathematics is, in large part, the search for patterns, and for the explanations as to why those patterns exist.

&#x09;

\-> ML is helpful as we cannot write cases/programs for each case

&#x09;-> As the data changes, ML algo automatically change their logic

&#x09;	(classifying email as spam or not)

&#x09;-> sometimes there are lot of cases such that we cannot write each case, so 

&#x09;	ML is useful (image classification)

&#x09;-> ML is used for data mining

&#x09;	-> sometimes patterns in data cannot be identified 

&#x09;	-> so we run the ML algorithm over the data

&#x09;	-> now we can see what patters the ML algo has created and use those

&#x09;	-> this is data mining



\-> Earlier data and hardware were not that good, so ML is not used 

\-> Today there is huge amount of data and good hardware that support that quantity of data. --> This causes ML to be useful
