**CHALLENGES IN ML**



1. Data Collection

&#x09;-> ML is learning from data

&#x09;-> data gathering is done through

&#x09;	-> fetch data from an API

&#x09;	-> Web scraping



2\. Insufficient data/ Labelled data

&#x09;-> A ML algorithm with lower performance than another algorithm with higher performance

&#x09;	perform better if it has more data than the other algorithm when solving

&#x09;	the same problem

&#x09;-> Unreasonable effectiveness of data : if we have huge amount of data, then

&#x09;	algorithm does not matter

&#x09;-> But since this amount of data is not very available so algorithm matters

&#x09;-> Also labelled data is difficult to get (means for the input the output is defined)



3\. Non representative data

&#x09;-> if we have a data that does not completely represent the output then it is

&#x09;	non representative data

&#x09;-> sometimes we get data from a particular domain only which leads to biased data

&#x09;-> this leads to wrong results



4\. Poor quality data

&#x09;-> data has

&#x09;	-> outliers

&#x09;	-> missing values

&#x09;-> we need to correct this

&#x09;->poor quality data leads to poor results



5\. Irrelevant features (features means input columns)

&#x09;-> features that has no impact on the output of ML models will give bad results

&#x09;-> Garbage in --> Garbage out

&#x09;-> we need to do feature engineering



6\. Overfitting

&#x09;-> Overfitting happens when a model is too complex and learns the training data too well



7\. Underfitting

&#x09;-> Underfitting happens when a machine learning model is too simple to capture the 

&#x09;	underlying patterns in the data



8\. Software integration

&#x09;-> it is need to integrate to the software 



9\. Offline learning / deployment

&#x09;-> deployment is costly
