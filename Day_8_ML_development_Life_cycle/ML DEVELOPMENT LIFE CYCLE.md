**ML DEVELOPMENT LIFE CYCLE**



\-> Software engineering

&#x09;-> SDLC (Software Development Life Cycle)

&#x09;	-> guide how to create the software product from starting to end



\-> ML development Life Cycle(MLDLC)

&#x09;-> guidelines for development of ML software



\-> we need to create a software product that has Machine Learning





\-> Steps for MLDLC



1. Frame the problem

&#x09;-> while starting understand problem, solution, type of model



2\. Gathering the data

&#x09;-> csv files

&#x09;-> fetch from API

&#x09;-> web scraping

&#x09;-> running database(main database)

&#x09;	-> we create data warehouse and fetch data from it (ETL)

&#x09;	-> Extract Transform Load

&#x09;-> Big data



3\. Data preprocessing

&#x09;-> data must be cleaned 

&#x09;-> Remove duplicates

&#x09;-> remove missing values

&#x09;-> remove outliers

&#x09;-> scale the values

&#x09;	-> one column has large values and other column values are small

&#x09;	-> we need to standardize the values



4\. Exploratory Data Analysis (EDA)

&#x09;-> study the relationship b/w input and output

&#x09;-> understanding the data

&#x09;-> data visualization

&#x09;-> univariate analysis

&#x09;-> bivariate analysis

&#x09;-> multivariate analysis

&#x09;-> Imbalance dataset convert to balanced dataset



5\. Feature engineering and selection

&#x09;-> feature (input columns)

&#x09;-> can combine related columns into new single columns (feature engineering)

&#x09;	-> create new useful feature

&#x09;	-> combine existing features intelligently

&#x09;-> feature selection : selecting the most impactful features on the output



6\. Model training, evaluation, selection

&#x09;-> bring different ML algorithms

&#x09;-> give data and train them

&#x09;-> evaluate the results of the model on the basis of performance matrices

&#x09;	-> MSE

&#x09;-> select the best model

&#x09;-> tune their parameters (hyperparameter tuning)

&#x09;-> Ensemble learning

&#x09;	-> we combine multiple ML models to create a powerful model



7\. Model deployment 

&#x09;-> deploy the model in the server

&#x09;-> customer use it through API



8\. Testing

&#x09;-> beta testing

&#x09;	-> give the software for test to some selected customers and get feedback



9\. Optimize

&#x09;-> retrain the model

&#x09;-> load balancing
